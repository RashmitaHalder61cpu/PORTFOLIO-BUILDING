# GitLens
GitLens teaches us that looking at code history should be easy and instant. You do not need to open a separate terminal or website to see who wrote a line.

# LiveShare
Live Share teaches us that coding is a social activity. You can invite team members straight into your workspace. You do not need to push code or share files manually just to fix a bug together.
