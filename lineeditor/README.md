# Simple Line Editor in C

## Team Members

1. Rashmita Halder
2. Priyanka C
3. Ranjitha MS

## Features Implemented

- Insert a line
- Delete a line
- Display the document

## Data Structure

The editor uses an array of strings to store document lines.

## How to Compile

Open the terminal in the lineeditor folder and run:

gcc line_editor.c -o editor.exe

## How to Run

Run:

.\editor.exe

## Commands

1. Insert Line
2. Delete Line
3. Display Document
4. Exit
