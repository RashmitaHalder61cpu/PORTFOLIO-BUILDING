## Project Description

A simple command-line line editor developed in C. The program allows users to insert, delete, display, search, replace, save, and load lines of text using a menu-driven interface.

## Features Implemented

### Core Features

* Insert a line
* Delete a line
* Display the document
* Save the document to a file
* Load the document from a file

### Bonus Features

* Search for a word or text
* Find and replace text
* Count lines and words

## Data Structure

The editor uses an array of strings to store document lines.

## Technologies Used

* C Programming Language
* GCC Compiler
* Visual Studio Code

## How to Compile

Open the terminal in the `lineeditor` folder and run:

```text
gcc line_editor.c -o line_editor.exe
```

## How to Run

Run:

```text
.\line_editor.exe
```
