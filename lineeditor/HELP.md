# Line Editor - Help

## 1. Insert Line

Adds a new line at the given line number.

Usage:
Choose option 1 and enter the line number and text.

Example:
Enter choice: 1
Enter line number: 1
Enter text: Hello World

## 2. Delete Line

Deletes a line from the document.

Usage:
Choose option 2 and enter the line number.

Example:
Enter choice: 2
Enter line number to delete: 1

## 3. Display Document

Displays all current lines with their line numbers.

Usage:
Choose option 3.

Example:
Enter choice: 3

Output:
1. Hello World

## 4. Exit

Closes the line editor.

Usage:
Choose option 4.
